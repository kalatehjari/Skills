# Summary

The slope behind Lot 12 has a factor of safety of 1.32 under static conditions.

# Method

Limit equilibrium analysis used the Morgenstern–Price method with $c' = 5$ kPa and $\phi' = 32^\circ$.[^1]

| Case | FoS |
|---|---|
| Static | 1.32 |
| Seismic | 1.08 |

[^1]: Parameters from triaxial tests on BH1 samples.
